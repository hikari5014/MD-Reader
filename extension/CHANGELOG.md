# 更新日誌

## v1.3.0 — 觸控互動(2026-09-22)

**白話說明**:在觸控筆電、平板上用手指操作也順手了。以前手指點完按鈕,按鈕會一直停在「滑鼠移上去」的樣子;現在點完就恢復。按下時底色會加深、圖示變實心;按鈕與目錄項目放大到手指好點的大小;長按工具列按鈕可以看說明;窄螢幕的浮動目錄可以用手指往左拖關掉。用滑鼠的操作完全不變。

### 新增
- **按下回饋**(沒有滑鼠的裝置):工具列按鈕、目錄、提示框標題、屬性表、設定頁選單、小視窗最近開過,按下時底色加深、圖示變實心;設定齒輪按下時轉一下
- **手指好點**:用手指操作時,工具列按鈕放大到 48px、目錄項目變高、提示框與屬性表標題至少 44px、設定頁選單 48px、輸入框字放大到 16px
- **長按看說明**:手指按住工具列按鈕 0.5 秒,按鈕慢慢沉下去,接著出現說明泡泡(支援的裝置會輕震);放手不會觸發按鈕
- **目錄抽屜往左拖關閉**(窄螢幕):拖的時候目錄跟著手指走,拖過三分之一或甩一下就關,小拖一下會彈回
- 小視窗「最近開過」的箭頭在觸控裝置上常駐顯示

### 修正
- 觸控螢幕上點完按鈕,「滑過」的底色、浮起、說明泡泡會一直黏著 → 所有滑過效果改成只在有滑鼠的裝置生效
- 手指按下後開始捲動時,水波紋會留著不消失 → 捲動時自動收掉

### 影響範圍
- 所有介面在觸控裝置上的手感;滑鼠操作與功能不變

### 技術細節
- 所有 `:hover` 規則包進 `@media (hover: hover)`(ui.css、reader.css、drive.css、popup.css、options.css);觸控規則用 `@media (hover: none)`、`@media (pointer: coarse)`
- `core/ui.js` 新增 `MDR.enableTouch`(長按說明)、`MDR.swipeToClose`(抽屜拖曳關閉),水波紋加上 `pointercancel`
- 自動化測試新增 4 項(第 13 組,用 Chrome 觸控模擬),共 89 項

## v1.2.0 — 載入與過場動畫(2026-09-22)

**白話說明**:等待的時候不再是一片空白或「載入中…」幾個字。開啟比較慢的檔案(例如 Google Drive、網路上的 .md)時,畫面中央會出現插件圖示輕輕呼吸、光圈向外擴散的過場;流程圖還在準備時先佔好位置轉圈;切換「排版 / 原始碼」時淡出淡入。很快就開好的檔案則完全不會閃出載入畫面。

### 新增
- **開檔過場**(閱讀頁):讀檔超過 0.3 秒才出現,出現後至少停 0.5 秒(不會閃一下就消失);從 Google Drive 開時顯示「正在從 Google Drive 讀取…」;讀完淡出並微微放大,露出排好的文件
- **流程圖載入中**:流程圖元件約 3.5MB,第一次載入時先放一個灰色佔位框,0.3 秒後浮出轉圈與「正在畫流程圖…」,畫好後圖淡入(畫面不會跳動)
- **排版 ↔ 原始碼切換**:舊畫面淡出、新畫面淡入並微微放大
- 系統設定了「減少動態效果」時,載入動畫改成柔和的明暗閃爍(不會完全停住,免得看起來像當機)

### 修正
- 流程圖語法錯誤的提示,原本用表情符號 ⚠️,改成與其他介面一致的 Google 圖示

### 影響範圍
- 閱讀頁(右鍵開啟、小視窗、Google Drive、開啟檔案頁開出來的畫面)、含流程圖的文件、工具列的原始碼按鈕;功能不變

### 技術細節
- `core/ui.js` 新增 `MDR.spinner`、`MDR.withLoader`(延遲 300ms 顯示、最短 500ms)、`MDR.pageLoader`(掛在 `<html>`,排版換掉 `<body>` 時不會被瞬間拿掉)、`MDR.swap`
- `styles/ui.css` 新增轉圈(Material 3 伸縮弧線)、不確定進度條、整頁過場、淡出淡入;「減少動態效果」的例外規則
- 自動化測試新增 5 項(第 12 組),共 85 項

## v0.4.0 — 看得懂 Obsidian 筆記、流程圖、數學公式(2026-09-18)

**白話說明**:Obsidian 筆記現在能漂亮顯示了:開頭的屬性變成屬性表、`[[雙中括號連結]]` 可以點、`> [!tip]` 變成彩色提示框,還有螢光筆、標籤、腳註、嵌入圖片。另外流程圖(Mermaid)和數學公式也會直接畫出來。
(原本規劃的 Google Drive 版順延為 v0.5,等 Drive 診斷結果)

### 新增
- **屬性表**:筆記開頭 `---` 包起來的屬性顯示成表格;清單變成標籤膠囊、勾選變成方框、網址和 `[[連結]]` 可以點。可在設定頁關掉
- **雙中括號連結** `[[筆記]]`、`[[筆記|顯示文字]]`、`[[筆記#段落]]`、`[[#段落]]`、`[[#^區塊]]`
  - 預設:找同一個資料夾裡的同名 .md
  - 設定頁填了「Obsidian 保險庫名稱」:直接在 Obsidian App 打開那篇筆記(不管放在哪個資料夾)

- **隱藏註解** `%%看不到%%`、**區塊 ID** `^abc` 不顯示,且能被 `[[#^abc]]` 連過去
- **嵌入** `![[圖.png]]`、`![[圖.png|300]]`:自動到附近的 `_attachments`、`attachments`、`assets`、`images` 資料夾找圖;`![[筆記]]` 顯示成可點的嵌入框
- **Mermaid 流程圖**:流程圖、循序圖等;跟著深淺色換配色;語法錯誤時顯示說明,不會整頁壞掉
- **數學公式**:`$行內$`、`$$區塊$$`(KaTeX);「$5、$10」這種價錢不會被誤判
- 設定頁「閱讀」新增:顯示屬性表(開關)、Obsidian 保險庫名稱

- 有流程圖的文件第一次打開會稍微慢一點(載入 3.5MB 的流程圖元件),沒有流程圖的文件不會載入

- 新增 `core/syntax.js`(markdown-it 外掛:wikilink、embed、math;前處理:註解、frontmatter)、`core/obsidian.js`(消毒後加工:callout、tag、block id、連結網址、嵌入圖片、屬性表)、`core/diagram.js`(Mermaid 延遲載入)

## v0.1.0 — 第 0 期技術驗證(2026-09-18)

**白話說明**:先做一個「最小但真的能用」的插件,用來確認四個入口會不會卡關。結果:本機、網路、下載三條路在自動化測試裡全部走通,Google Drive 需要你登入後實測。

### 新增
- 本機 .md 檔用 Chrome 打開時,自動換成排版好的閱讀畫面(中文、表格、程式碼、引用)
- 網路上的 .md 網址自動排版,包含:沒宣告編碼的(中文不亂碼)、網站強制下載的(改成直接顯示)、有嚴格安全設定的(像 GitHub raw)
- 下載完 .md 檔會跳通知,點通知就用新分頁打開並排版
- 第一次安裝時,如果還沒開「允許存取檔案網址」,自動打開繁中圖解引導頁,開好會即時變綠色
- 閱讀頁(給 Drive、Windows 等不能就地排版的情況用)
- 安全消毒:MD 檔裡夾帶的惡意程式碼一律擋掉
- Google Drive 診斷按鈕(暫時的,實驗用)
- 插件圖示

### 修正
- (第一版,無)

### 影響範圍
- 新專案,無既有功能受影響
- 插件會在所有 .md 網址載入;本來就是網頁的 .md(例如 GitHub 的檔案頁)不會被動到

### 技術細節
- Manifest V3,最低 Chrome 128;markdown-it 14.3.2 + DOMPurify 3.4.15,放在 `extension/vendor/`
- 網路規則(declarativeNetRequest):`.md` 網址且回應帶 `content-disposition: attachment` → 移除;回應沒宣告編碼且不是 HTML → 改成 `text/plain; charset=utf-8`
- 下載:`chrome.downloads.onChanged` 完成 → `chrome.notifications` → 點擊後 `chrome.tabs.create(file://…)`(Chrome 118+ 需檔案存取權限,沒有時改開引導頁)
