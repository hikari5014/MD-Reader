# MD隨手讀 使用說明

MD隨手讀 讓 Chrome 把 Markdown(.md)檔排版成好讀的樣子。不管檔案來自電腦、網路、下載還是 Google Drive,打開就能讀;Obsidian 筆記的屬性表、雙中括號連結、提示框也看得懂。

> [!tip] 第一次使用
> 要看**電腦裡**的 .md,請先到「設定 → 🔐 檔案權限」照步驟打開「允許存取檔案網址」。這是 Chrome 的規定,只能由你親手打開。

## 五種打開方式

| 從哪裡 | 怎麼開 |
|---|---|
| 💻 電腦裡的檔案 | 把 .md **拖進 Chrome 分頁**(最推薦,圖片也能顯示);或點工具列的 MD隨手讀 圖示 →「📂 開啟電腦裡的 .md」 |
| 🌐 網路上的 .md | 直接點開就會排版;網站如果強制下載,也會改成直接顯示 |
| 🖱️ 網頁上的 .md 連結 | 按右鍵 →「用 MD隨手讀 開啟」;GitHub、GitLab 的檔案頁也行 |
| ⬇️ 下載的 .md | 下載完右上角跳通知,點通知就打開(可在設定改成自動開或不處理) |
| ☁️ Google Drive | 看到 .md 時,右下角按紫色的「用 MD隨手讀 開啟」 |

另外,小視窗的貼上框可以貼一段 Markdown 文字(直接排版)或一個網址(打開那個網址)。

💡 想**雙擊 .md 就用 Chrome 打開**:Mac 在 .md 上按右鍵 → 取得資訊 → 打開檔案的應用程式選 Google Chrome → 全部更改;Windows 按右鍵 → 開啟檔案 → 選擇其他應用程式 → Google Chrome → 一律使用。

## 閱讀畫面

右上角的工具列:

| 按鈕 | 作用 |
|---|---|
| 目錄(三條線) | 打開 / 收起左邊的目錄。點目錄項目會跳過去,捲動時會標出讀到哪一段 |
| 主題(會跟著目前主題變:自動 / 太陽 / 月亮 / 眼鏡) | 依序切換 跟隨系統 → 淺色 → 深色 → 護眼 |
| 原始碼(`< >`) | 切換成原始 Markdown 文字;再按一次回到排版畫面 |
| 列印(印表機) | 列印或存成 PDF,只印內文 |
| 設定(齒輪) | 打開設定頁;出現**小紅點**代表插件更新了,點了直接看更新日誌 |

滑鼠停在按鈕上會出現中文說明。

畫面最上面的細線是閱讀進度。

## Obsidian 筆記

看得懂:屬性表、`[[雙中括號連結]]`、`> [!tip]` 提示框(可收合、可巢狀)、`==螢光筆==`、`#標籤`、`%%註解%%`、`^區塊ID`、`![[嵌入圖片]]`、腳註、Mermaid 流程圖、`$數學公式$`。

> [!note] 讓雙中括號連結直接開 Obsidian
> 到「設定 → 📖 閱讀 → Obsidian 保險庫名稱」填你的保險庫名稱(例如 `LLM Wiki`)。之後點 `[[連結]]` 會直接在 Obsidian App 打開那篇筆記,不管它放在哪個資料夾。
> 沒填的話,連結會找「同一個資料夾」裡的同名 .md。

嵌入圖片 `![[圖.png]]` 會自動到附近的 `_attachments`、`attachments`、`assets`、`images` 資料夾找。

## Google Drive

Google 自己的預覽已經能顯示一般 Markdown。MD隨手讀 的按鈕是給 **Obsidian 語法**用的(提示框、雙中括號連結、屬性表、流程圖、公式 Google 看不懂)。按鈕會出現在三個地方:

- Drive 的檔案預覽
- 用 Google 文件打開的 .md(Markdown 模式)
- Drive 列表裡點了一個 .md 時

也可以在 Drive 分頁點工具列的 MD隨手讀 圖示,小視窗最上面會直接出現「用 MD隨手讀 開啟 這個檔案」。

## 設定一覽

| 分頁 | 可以調的 |
|---|---|
| 🎨 外觀 | 主題(跟隨系統 / 淺色 / 深色 / 護眼)、字級、版面寬度 |
| 📖 閱讀 | 顯示目錄、閱讀進度條、顯示屬性表、Obsidian 保險庫名稱、Google Drive 按鈕、記錄最近開過的檔案、清除最近紀錄 |
| ⬇️ 下載 | 下載到 .md 時:跳通知 / 自動開 / 不處理 |
| 🔐 檔案權限 | 目前是否能讀電腦裡的 .md,以及開啟方法 |

設定會跟著你的 Google 帳號同步到其他電腦(Chrome 有登入同一個帳號時)。

## 常見問題

**拖進 Chrome 還是一坨純文字?**
還沒開「允許存取檔案網址」。到「設定 → 🔐 檔案權限」照步驟開啟,再重新整理那一頁。

**下載完沒有跳通知?**
先確認「設定 → ⬇️ 下載」選的是「跳通知」。Mac 要到「系統設定 → 通知 → Google Chrome」允許通知;Windows 到「設定 → 系統 → 通知」確認 Chrome 已開啟。

**Windows 上拖進 .md 變成下載?**
有些 Windows 電腦會這樣。MD隨手讀 會自動用閱讀頁打開原檔;如果沒有,請到「設定 → 🔐 檔案權限」確認已開啟。

**Drive 上沒看到按鈕?**
插件剛安裝或更新時,已經開著的分頁要重新整理(⌘R)一次才會有 MD隨手讀 的功能;在 Drive 分頁打開小視窗也會提醒你。

**Drive 按下去說沒有權限?**
可能沒登入擁有這個檔案的帳號。改用 Drive 的「下載」,下載完 MD隨手讀 會跳通知幫你打開。

**圖片顯示「找不到圖片」?**
圖片不在筆記旁邊或常見的附件資料夾裡。用 Obsidian 打開同一篇筆記就能看到。

**改了檔案,畫面沒更新?**
按 ⌘R(Windows 按 Ctrl+R)重新整理即可。

## 隱私

- 所有排版都在你的電腦上完成,文件內容不會傳到任何伺服器。
- 「最近開過」和小視窗貼上的文字只存在這台電腦,可在設定清除。
- 只有你的設定(主題、字級等)會透過 Chrome 同步到你自己的其他電腦。
