    7原計劃 vs 實際(並排對照)

    做的過程中發現新資訊時的調整,以及背後的理由。

    項目v0.1 計劃實際為什麼
    Google Drive在 Drive 預覽裡把純文字換成排版改成「用 MD隨手讀 開啟」按鈕,專看 Obsidian 語法做到一半發現 Google 已經能自己排版一般 .md,不需要再搶;Google 看不懂的是 Obsidian 語法
    小視窗選檔、拖放區、貼上拖放拿掉、選檔改開分頁、貼上框自動判斷文字或網址Chrome 小視窗一失去焦點就關閉,從 Finder 拖檔或打開選檔視窗都會讓它先關掉
    版本號v0.4 Drive、v0.5 Obsidianv0.4 Obsidian、v0.5 Drive先做不用等實驗的 Obsidian;版本號代表做出來的順序
    下載設定v0.3 才做提前到 v0.2你要求加設定頁,下載行為是第一個需要設定的項目
    新增—插件內更新日誌、使用說明、新版本小紅點、不標準屬性容錯你要求在插件裡看更新日誌;v1.0 補上使用說明
    不做構想中檔案改了自動更新、嵌入筆記展開、右鍵排版選取文字前兩項 Chrome 不讓本機頁面讀其他本機檔;第三項 Chrome 給的選取文字會丟掉換行
    安全DOMPurify 消毒消毒 + 流程圖 SVG 也消毒 + 雙中括號連結禁止 javascript: 網址v1.0 自我檢查找到並修掉一個連結漏洞,已加進惡意範例檔永久測試
