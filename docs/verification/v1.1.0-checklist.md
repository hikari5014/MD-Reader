# v1.1.0 驗收清單(介面與互動重新設計)

> 🤖 自動化測試 **80/80 通過**(新增 5 項互動測試:圖示字型、提示泡泡、水波紋、分段按鈕色塊、減少動態效果)。

## 🎯 圖示與互動
- [ ] **閱讀畫面工具列**(把任一 .md 拖進 Chrome):五顆按鈕都是 Google 風格的圓角圖示
  - [ ] 滑鼠移上去:圖示從線條變成實心、底色變淡紫;停一下出現黑色中文說明泡泡
  - [ ] 按下去:按鈕微縮,從按的位置泛起一圈水波紋
  - [ ] 主題按鈕:每按一下,圖示在「自動 → 太陽 → 月亮 → 眼鏡」間變化,會轉一圈出現
  - [ ] 原始碼按鈕:按下後圖示變成「文章」,再按變回「程式碼」
  - [ ] 設定(齒輪):滑過時會轉一點
- [ ] **目錄**:滑過項目時左側長出紫色指示條,目前段落的指示條完整顯示
- [ ] **提示框**:`test-files/obsidian-note.md` 的「點我展開」提示框,展開/收起是平滑的、右邊箭頭會轉
- [ ] **小視窗**:最近開過的每一列滑過時,左邊圖示變紫、右邊浮出箭頭;按鈕都有水波紋
- [ ] **設定頁**
  - [ ] 左側選單:目前分頁有紫色指示條、圖示變實心
  - [ ] 外觀 → 主題:點不同選項,白色選中色塊會**滑過去**
  - [ ] 閱讀 → 開關:開啟時圓鈕變大、出現勾勾、有一點彈性
  - [ ] 下載 → 選項卡片:滑過浮起;選中時右邊圓點彈一下
  - [ ] 改任何設定:下方「已儲存」從下面彈上來
- [ ] **Google Drive**:選取 .md → 右下角按鈕從下方滑入;滑過時浮起、圖示微微傾斜
- [ ] **權限引導頁**、**開啟檔案頁**:都是新圖示,按鈕有同樣的手感
