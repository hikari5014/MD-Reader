## 🎯 新功能

### 實驗 1:本機檔案(Mac)
- [ ] 把 `test-files/sample-zh.md` **拖進 Chrome** → 看到排版好的畫面(標題、表格、灰底程式碼、紫色引用線)
- [ ] 最下面的驗證碼顯示 `MDR-ZH-OK-繁中正常`(中文沒有亂碼)
- [ ] `test-files/測試 中文檔名.md`(檔名有空格和中文)也能排版
- [ ] (選做)在 Finder 對任一 .md 按右鍵 → **取得資訊** → 打開檔案的應用程式選 **Google Chrome** → **全部更改**。之後雙擊 .md 就直接用 Chrome 排版打開

### 實驗 2:下載的 .md
- [ ] 先確認 Mac 允許 Chrome 發通知:**系統設定 → 通知 → Google Chrome → 允許通知**(沒開的話通知不會出現)
- [ ] 到 Google Drive 對任一 .md 檔按右鍵 → **下載**(Drive 的下載一定會觸發真正的下載)
- [ ] 下載完成後,右上角跳出「MD隨手讀:下載了一份 Markdown」通知
- [ ] 點通知 → 開新分頁並排版

### 實驗 4:網路上的 .md
- [ ] 打開 <https://raw.githubusercontent.com/simov/markdown-viewer/main/README.md> → 排版顯示
- [ ] 打開 <https://github.com/simov/markdown-viewer/blob/main/README.md> → **維持 GitHub 原本的樣子**(不應被動到)

### 實驗 3:Google Drive(網頁版)
- [ ] 上傳 `test-files/sample-zh.md` 到你的 Google Drive(網頁版)
- [ ] 在 Drive 裡**雙擊**這個檔案打開預覽 → 右下角應有紫色「🧪 MD隨手讀 Drive 診斷」按鈕
- [ ] 按下按鈕 → 等幾秒出現診斷結果 → 按 **📋 複製診斷結果** → 貼回給 Claude
- [ ] 再試一次:在 Drive 檔案**列表**裡「單擊選取」這個檔案(不打開)→ 按診斷 → 複製結果貼回
- [ ] (選做)對這個檔案按右鍵 → **分享 → 複製連結** → 用新分頁打開這個連結 → 按診斷 → 複製結果貼回
