## 🎯 新功能

### 工具列小視窗(點網址列右邊的 MD隨手讀 圖示;看不到就按 🧩 拼圖 → 📌 釘選)
- [ ] 點圖示 → 跳出小視窗,上面寫「MD隨手讀 v0.3.0」
- [ ] **📂 開啟電腦裡的 .md** → 開出「開啟電腦裡的 Markdown 檔」分頁 → 按「選擇檔案」選 `test-files/sample-zh.md` → 變成排版畫面
- [ ] **貼上文字**:在貼上框貼這段,按「排版給我看」(或 ⌘ + Enter)→ 新分頁排版,有兩個勾選框
  ```
  # 貼上測試
  - [x] 完成
  - [ ] 未完成
  ```
- [ ] **貼上網址**:貼 `https://raw.githubusercontent.com/simov/markdown-viewer/main/README.md` → 新分頁排版
- [ ] **最近開過**:剛剛開過的文件都在清單裡,標著「本機 / 網路 / 貼上」和時間;點任一筆能重新打開
- [ ] 下方 **⚙️ 設定** → 打開設定頁;**📜 更新日誌** → 直接跳到更新日誌,v0.3.0 有「目前版本」標籤

### 右鍵開啟
- [ ] 打開 <https://github.com/simov/markdown-viewer>,在檔案列表的 **README.md** 連結上按右鍵 → 選單裡有「用 MD隨手讀 開啟」→ 點下去 → 旁邊開新分頁、排版顯示
- [ ] 在沒有 .md 的連結(例如一般網頁連結)上按右鍵 → **不會**出現這個選項

### 設定頁「閱讀」
- [ ] 關掉「記錄最近開過的檔案」→ 再開一份 .md → 小視窗的清單沒有增加,顯示「已關閉紀錄」
- [ ] 打開回來 → 按「清除最近紀錄」→ 小視窗清單變空
