# v0.5.0 驗收清單(Google Drive)

> 🤖 自動化測試 **66/66 通過**(含 10 項 Drive:其中 3 項連到真正的 Google Drive);🗂 真實筆記 **20/20**。
> 🙋 **需要你用自己的 Google 帳號測**(自動化測試沒辦法登入你的 Drive),約 5 分鐘。
> 🔄 先到 `chrome://extensions` 按 MD隨手讀 的 🔄 重新載入。

---

## 🎯 新功能

### 準備
- [ ] 把 `test-files/obsidian-note.md` 上傳到你的 Google Drive(網頁版)

### 三個地方會出現按鈕
- [ ] **Drive 列表**:單擊選取這個檔案(不打開)→ 右下角出現紫色「📖 用 MD隨手讀 開啟 obsidian-note.md」
- [ ] **預覽**:對檔案按右鍵 →「開啟檔案」→「預覽」→ 右下角出現同樣的按鈕
- [ ] **Google 文件**:雙擊檔案(用 Google 文件的 Markdown 模式打開)→ 右下角出現同樣的按鈕
- [ ] 選一個 PDF 或圖片 → **不會**出現按鈕

### 按下去
- [ ] 旁邊開新分頁,顯示 MD隨手讀 的排版:屬性表、提示框、螢光筆都正常(Google 自己的預覽看不懂這些)
- [ ] 小視窗「最近開過」出現這份,標著 ☁️ Drive

### 讀不到的情況
- [ ] 用另一個**沒登入**的 Chrome 設定檔(或無痕視窗,需在擴充功能詳細資料允許無痕)打開別人私人的 .md 連結 → 按按鈕 → 閱讀頁說明「沒有權限…可以改用 Drive 的『下載』」

### 設定
- [ ] 設定頁「閱讀」→ 關掉「Google Drive 按鈕」→ Drive 上的按鈕消失;打開回來

## 🔗 跨功能影響
- [ ] 在 Drive 對 .md 按右鍵「下載」→ 仍會跳「MD隨手讀:下載了一份 Markdown」通知
- [ ] Gmail、Google 日曆等其他 Google 服務沒有出現任何按鈕

## 🎨 UI/UX
- [ ] 按鈕不會擋住 Drive 右下角的重要按鈕(若有擋到,截圖給 Claude)

## ⚠️ 邊界情況
- [ ] 按鈕在 Drive 切換資料夾、關閉預覽後會自動消失(最多延遲 1 秒)
