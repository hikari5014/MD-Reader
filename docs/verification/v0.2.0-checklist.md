## 第一步:把插件裝進 Chrome(只做一次)

1. 打開 Finder,找到專案資料夾 `Claude Work Space/Claude Code/chrom閱讀MD插件`
2. Chrome 網址列輸入 `chrome://extensions` 按 Enter
3. 右上角 **開發人員模式** 打開
4. 左上角按 **載入未封裝項目** → 選資料夾裡的 **`extension`** → 按「選取」
5. 看到「MD隨手讀 0.2.0」的卡片就是裝好了
6. 按卡片上的 **詳細資料** → 往下捲 → **允許存取檔案網址** 打開
7. (建議)按網址列右邊的 🧩 拼圖 → 在 MD隨手讀 旁按 📌 圖釘,讓圖示固定在工具列

- [ ] 裝好了
- [ ] 👀 **觀察**:按下「選取」的那一刻,有沒有自動跳出「🔓 還差一步」引導頁?(有/沒有 → 告訴 Claude)

> 🔄 **之後每次 Claude 改了程式**:回到 `chrome://extensions`,按 MD隨手讀 卡片右下的 🔄 重新載入,再重新整理 .md 分頁。
