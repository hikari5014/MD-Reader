# v1.3.0 驗收清單(觸控互動)

> 🤖 自動化測試 **89/89 通過**(新增 4 項:觸控時按鈕放大且不黏住、長按看說明、目錄往左拖關閉、滑鼠裝置不受影響)。
> 🙋 需要**觸控螢幕**(觸控筆電、Windows 平板);Mac 沒有觸控螢幕,可以用 Chrome 開發者工具模擬(見最後一節)。約 3 分鐘。
> 🔄 先到 `chrome://extensions` 按 MD隨手讀 的 🔄 重新載入,已開著的 .md 分頁要重新整理。

## 👆 觸控
- [ ] 用手指點工具列的「主題」:點完按鈕**不會**一直停在淡紫底色
- [ ] 按下的瞬間:底色加深、圖示變實心、有水波紋
- [ ] 手指按住「原始碼」按鈕不放:按鈕慢慢縮小 → 約半秒後出現說明泡泡;放手**不會**切到原始碼
- [ ] 按鈕比用滑鼠時大一圈,手指好按
- [ ] 把視窗縮窄 → 開目錄 → 手指在目錄上往左拖:目錄跟著手指走;拖一點點放手會彈回,拖多一點放手會關掉
- [ ] 目錄上下捲動仍然正常(不會被當成拖曳)

## 🖱️ 滑鼠(確認沒被影響)
- [ ] 用滑鼠滑過工具列按鈕:照舊出現淡紫底色與說明泡泡

## 🧪 Mac 沒有觸控螢幕時怎麼測
- 在 .md 頁面按 ⌥⌘I 開開發者工具 → 按左上角的手機圖示(切換裝置工具列)→ 選一個平板 → 重新整理頁面。滑鼠就會被當成手指。
