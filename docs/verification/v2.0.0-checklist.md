# v2.0.0 驗收清單(iPhone 網頁 App)

> 🤖 自動化測試:手機版 **22/22 通過**(用 Chromium 模擬 iPhone 13);插件 89/89、真實筆記 20/20。
> 🙋 以下要用**你的 iPhone** 實機測,約 10 分鐘。網址:**https://hikari5014.github.io/MD-Reader/pwa/**
> ⚠️ 模擬器不是真的 Safari:加入主畫面、選檔視窗、Google 登入跳轉、震動,只有實機才準。

---

## 📱 安裝
- [ ] iPhone 用 **Safari** 打開上面網址 → 首頁上方有紫色「加到主畫面」提示
- [ ] 點 Safari 的分享 →「加入主畫面」→ 主畫面出現紫色 MD↓ 圖示,名稱「MD隨手讀」
- [ ] 從主畫面打開:全螢幕、沒有網址列;上方不會被瀏海蓋住

## 📂 開檔
- [ ] **選擇檔案** → 從「檔案」App / iCloud Drive 選一個 .md → 排版顯示(提示框、屬性表、公式)
- [ ] 選檔視窗裡 .md **不是灰色**、可以選
- [ ] 選一張照片 → 提示「不是文字檔」,留在首頁
- [ ] (有裝 Google Drive App)選擇檔案 → 左上「瀏覽」→ 看得到 Google Drive → 可以挑 .md
- [ ] **貼上文字**:從備忘錄複製一段 Markdown → 貼上 → 開啟;試「從剪貼簿貼上」按鈕(會跳出「貼上」確認)
- [ ] **輸入網址**:貼 `https://github.com/simov/markdown-viewer/blob/main/README.md` → 開啟

## 📖 閱讀
- [ ] 左上返回鍵回首頁;右上工具列:目錄、主題、原始碼、齒輪
- [ ] 齒輪 → 底部面板:字級 A− / A+、行寬、主題切換立即生效;面板可以往下拖關掉
- [ ] 「分享這份文件」→ 出現 iPhone 分享選單,可以存到「檔案」、傳 LINE / 郵件
- [ ] 點文件裡的雙中括號連結 → 出現說明(手機版不能開同資料夾其他筆記)
- [ ] (有裝 Obsidian)齒輪 → 保險庫名稱填 `LLM Wiki` → 再點連結會打開 Obsidian
- [ ] 長按工具列按鈕 → 出現說明泡泡

## 🕘 最近開過、離線
- [ ] 開過的文件出現在首頁「最近開過」;同一個檔再開不會重複
- [ ] **開飛航模式** → 從主畫面打開 App → 首頁、最近開過的文件都能看
- [ ] 設定(右上)→ 清除最近開過

## ☁️ Google Drive 登入(要先照 `docs/guide/PWA-GOOGLE-DRIVE.md` 申請用戶端 ID)
- [ ] 首頁 Google Drive → 用 Google 帳號登入 → 會跳到 Google 頁面 → 同意後**回到 App**
- [ ] 列出雲端硬碟的 .md;搜尋檔名;點一個 → 排版顯示
- [ ] ⚠️ 最需要回報:如果登入後停在 Google 頁面、或回到 Safari 而不是主畫面 App,請截圖
