> 🤖 手機版自動化測試 **28/28 通過**(新增 6 項:五種格式、分享被擋自動下載、使用者取消)。
> 🙋 約 5 分鐘。網址 **https://hikari5014.github.io/MD-Reader/pwa/**;已加到主畫面的話,先從主畫面打開並**下拉重新整理**一次拿到新版。

---

## 🖥 電腦(先確認你原本的錯誤修好了)
- [ ] 打開任一份文件 → 齒輪 →「分享 / 匯出」→ 選「Markdown 原始碼」
- [ ] **不再出現「分享失敗:Permission denied」**,而是直接下載 `.md`,並顯示「已下載到這台裝置」

## 📤 五種格式(電腦或手機都可以試)
- [ ] **Markdown 原始碼**:下載的 .md 用文字編輯器打開,內容與原文相同
- [ ] **整頁圖片**:下載的 .png 是整篇長圖;**提示框左邊是圖示,不是英文字**;中文、程式碼、表格都正常
- [ ] **PDF**:開啟列印畫面 → 存成 PDF;PDF 裡**沒有**返回鍵、工具列;文字可以選取
- [ ] **Word 文件**:下載的 .doc 用 Word 或 Pages 打開;標題、表格、引言(原本的提示框)正常;數學公式變成 `$公式$` 文字
- [ ] **存成 Google 文件**(要先設定 Google 登入,見 `docs/guide/PWA-GOOGLE-DRIVE.md`):
  - [ ] 首頁 → Google Drive → 登入(**如果之前登入過,要先登出再登入**,因為多了「建立檔案」權限)
  - [ ] 回到文件 → 齒輪 → 分享 / 匯出 →「存成 Google 文件」→ 出現「打開 Google 文件」按鈕 → 點了能開
  - [ ] 雲端硬碟裡出現同名的 Google 文件,內容正常

## 📱 iPhone
- [ ] 選 Markdown / 圖片 / Word → 跳出 iPhone 的分享選單,可以「儲存到檔案」或傳給別的 App
- [ ] 在分享選單按「取消」→ 不會跳錯誤、也不會重複下載
- [ ] PDF:列印畫面 → 兩指放大預覽 → 右上分享 → 儲存為 PDF
