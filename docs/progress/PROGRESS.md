### 遇到的問題
- DOMPurify 會擋 `obsidian://` 網址 → 解析時只寫 `data-href`,消毒後再依設定填網址(順便讓改設定能即時生效)
- 注入網頁的 CSS 裡,KaTeX 字型的相對路徑會對到網頁而不是插件 → 同步時改寫成 `chrome-extension://__MSG_@@extension_id__/…`
- Mermaid 3.5MB 不適合每頁都載 → 一般網頁由背景管家用 `chrome.scripting` 注入(白名單)、插件頁面直接加 `<script>`;沒流程圖的文件完全不載
- 標籤判斷:「、#標籤」緊貼標點時 Obsidian 不算標籤,插件照做(一開始測試檔寫錯)
- 數學公式數量算錯(錯誤公式不算 .katex)→ 修正測試預期值
